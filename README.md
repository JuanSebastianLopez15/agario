# Como probar el juego?

### En el mismo pc
1. ejecutar el proyecto (darle RUN)
2. Ponerle nombre al host (cualquiera) y marcar la casilla de "Eres el host"
3. Dale a jugar
4. Vuelve a darle a RUN, asegurate de tener el Allow multiple instances, si no lo tienes, ve al main de la parte superior, luego dale a 'Edit config', luego a 'Modify options' y a 'Allow multiple instances', Oprime a Aplicar y salte.
5. Pon el Nombre de Jugador2 en la nueva ventanam no marques la casilla del host y en la 'ip del host' escribe 'localhost' o '127.0.0.1'

### En diferentes pcs
1. Busca cual es la ip del host (en tu pc), abre la terminal -> ingresa este comando 'ipconfig' y presiona enter, busca la linea de Direccion IPv4 (ej: 192.168.1.15)
2. Abre el juego, pon un nombre, marca la casilla de host y dale jugar.
3. En el otro pc, ejecuta el juego, pon el nombre, no marques la casilla de Host y en la 'ip del host' escribe el numero que obtuviste en el paso 1.
4. Luego darle a jugar y todo deberia de funcionar correctamente.
